# Atajos de WezTerm

Configuración predeterminada (el `wezterm.lua` no define atajos personalizados).

## Pestañas

| Atajo | Acción |
|---|---|
| `Ctrl+Shift+T` | Nueva pestaña |
| `Ctrl+Shift+W` | Cerrar pestaña actual (pide confirmación) |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Siguiente / anterior pestaña |
| `Ctrl+Shift+1`…`9` | Ir a pestaña n.º N (`9` = la última) |
| `Ctrl+Shift+PageUp/PageDown` | Mover la pestaña actual de posición |
| `Ctrl+Shift+N` | Nueva ventana |
